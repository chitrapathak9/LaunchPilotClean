# LaunchPilot

Your AI Cofounder for Building Startups.

Validate startup ideas, generate MVP roadmaps, and launch faster with AI-powered guidance.

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Supabase
- Lucide React

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
